Configuración del sistema
=========================
              CPU mínima: 200
         CPU recomendada: Pentium II 266 (o superior)
              RAM mínima: 32 Megabytes
         RAM recomendada: 32 Megabytes

      Video recomendado : Cualquiera
   

Compatibilidad con DirectX 6
============================
Este juego requiere DirectX 6 para habilitar todas sus funciones. Puede
funcionar con versiones anteriores de DirectX, pero no se garantiza.



WINDOWS NT Y VERSIONES ANTERIORES DE DIRECTX
============================================
Enemy Infestation fue diseñado para Windows 95 y no ofrece soporte específico
para Windows NT. Si intentas ejecutarlo bajo Windows NT, puedes iniciarlo
escribiendo 'ei -k' en la línea de comandos. El mismo parámetro aplica para
versiones de DirectX anteriores a la versión 6.
No podrás escuchar la música de fondo si usas el parámetro '-k'.

Controlador de sonido
=====================
Usuarios de Windows 95:

Existe un problema conocido al usar el controlador Windows Sound System mientras
se ejecuta EI. Si escuchas ruidos de estática fuerte ocasionales durante la
partida, te recomendamos actualizar los controladores de tu tarjeta de sonido.
Como alternativa, si tu tarjeta admite emulación SoundBlaster, usa el
controlador SB16. Puedes elegir SB16 en el Panel de control -> Multimedia ->
Reproducción -> Dispositivo preferido -> SB16 Wave Out.


Rendimiento
===========
Cuanto más completa sea la instalación, más rápido correrá el juego. Si elegiste
una instalación mínima, el juego intentará copiar los mapas al disco duro al
cargar un nivel. Cada mapa ocupa unos 30 MB, lo cual acelera notablemente el
juego. Los mapas solo se copian si hay al menos 40 MB libres en la unidad donde
está instalado EI y se eliminan automáticamente al cerrar el juego.


Otras formas de acelerar el juego
=================================
* Realizar una instalación completa (todos los archivos en el disco duro)
* Desactivar la música del juego (desliza el volumen totalmente a la izquierda)
* Usar una tarjeta de video con buena aceleración 2D




NOTAS DE JUEGO
==============

Orden de escenarios
-------------------
Los episodios aparecen en orden, pero puedes seleccionar hasta 3 episodios
por delante del último que hayas completado. Así, si te quedas atascado en un
nivel, puedes seguir avanzando en uno posterior.

Se recomienda jugarlos en orden.

Aparecerá una marca junto a cada nivel que hayas completado con éxito.

Solo podrás elegir el nivel final después de haber completado el anterior.


SOLUCIÓN DE PROBLEMAS
=====================
Si encuentras fallos menores durante la partida, por ejemplo si alguno de tus
colonos se queda atascado, prueba guardar la partida y volver a cargarla
(en modo para un jugador). Guardar y cargar limpia el estado del juego y suele
resolver estos problemas.
